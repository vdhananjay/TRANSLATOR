Translation

Try it in the browser console

  • domElements.p1 gets the P1 DOM element.
  • paragraphElements[1] gets the element at index 1.
  • spliceParagraphs(1, 1) removes the element at index 1.
  • spliceParagraphs(1, 0, createParagraph("New paragraph")) inserts at index 1.
  • insertParagraphAt, removeParagraphAt, and updateParagraphAt are shared by the voice commands and the page controls.
  • runVoiceCommand("insert paragraph at index 1 saying Hello") runs a voice command from the browser console.
  • Calculate with add(8, 2), subtract(8, 2), multiply(8, 2), or divide(8, 2).
  • ScrabbleWordGame inherits the shared word-list behavior from WordGame.
  • Use scrabbleGame.addWord("NEW", "Recently made or discovered.") to extend its dictionary.
  • The word game instance and dictionary are available as scrabbleGame and scrabbleWords.
